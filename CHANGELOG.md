# Journal du projet

Toutes les dates des premières versions sont des repères issus de l’historique Git : le projet a commencé dans la vraie vie avant d’être correctement archivé.

## Les repères de Roland — 2026

Nouvelle édition publique de **Les repères de Roland**, en hommage à Roland.

- rassemble les idées conservées dans les branches historiques ;
- remplace la base MySQL historique par une base SQLite autonome ;
- propose une administration responsive en AJAX avec jQuery ;
- ajoute tâches, routines, couleurs, messages datés et modèles de messages ;
- rend l’heure et la date permanentes sur l’écran tablette ;
- introduit un journal d’actions et une visio WebRTC à décrochage automatique ;
- documente les intégrations domotiques sans les activer par défaut ;
- prépare le projet à être compris et adapté par d’autres familles.
